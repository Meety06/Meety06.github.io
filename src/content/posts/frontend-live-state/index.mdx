> 파트별 글 형식을 확인하기 위한 예시입니다.

## 문제

실시간 회의 화면은 녹음 상태와 서버 연결 상태를 함께 보여줘야 합니다. 두 상태를 여러 boolean으로 관리하면 불가능한 조합이 생기기 쉽습니다.

## 방법

화면 상태를 하나의 값으로 관리합니다.

```ts
type MeetingState = 'idle' | 'connecting' | 'recording' | 'paused' | 'error'
```

버튼과 안내 문구는 이 값을 기준으로 렌더링합니다. WebSocket 이벤트도 상태 전이만 담당하게 두면 UI 조건문이 줄어듭니다.

## 확인

- 연결 중 중복 입장 방지
- 일시 정지 후 재개
- 연결 종료 시 녹음 정리
- 오류 후 다시 연결
