# Meety Tech Blog

Meety 팀이 서비스를 만들며 부딪힌 문제와 풀어낸 과정을 기록하는 기술 블로그입니다.

**블로그: https://meety06.github.io/**

Astro + [Litos](https://github.com/Dnzzk2/Litos)

```bash
pnpm install
pnpm dev
pnpm build
```

글은 `src/content/posts/<slug>/index.mdx`에 작성합니다.

`main` 브랜치에 push하면 GitHub Pages로 배포됩니다. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정하세요.
